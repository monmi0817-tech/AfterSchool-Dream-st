# 방과후 신청양식 자동작성

프로그램 정보, 학생 정보, 부서별 학생 명단을 매칭하여 방과후 프로그램 신청 엑셀 양식을 생성하는 Windows 데스크톱 앱입니다.

## 개인정보 저장

업무 데이터는 외부 서버로 전송되지 않으며 기본적으로 사용자 PC의 `문서\방과후신청양식_데이터` 폴더에 저장됩니다. 앱을 업데이트하거나 재설치해도 이 데이터 폴더는 유지됩니다.

## 개발 실행

```bash
npm install
npm start
```

## Windows 설치파일

```bash
npm run dist:win
```

상세 배포 방법은 `RELEASE_GUIDE.md`를 참고하세요.
